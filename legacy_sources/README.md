# Legacy sources

This directory preserves historical standalone ppigFinder scripts and upstream
legacy snapshots for reproducibility and provenance.

These files are not the active application entry point. The current package
entry point is:

```bash
python main.py
```

or, when installed as a package:

```bash
ppigfinder
```

## Preserved files

- `ppigfinder_v20_root.py` — historical standalone v2.00 script previously kept at repository root.
- `genome_batch_v1_02.py` — historical genome-batch standalone script previously kept at repository root.
- `ppigfinder_v29_11_7.py` — archived upstream legacy source.
- `ppigfinder_v29_14.py` — archived upstream v29.14 source used for the active legacy GUI promotion.
