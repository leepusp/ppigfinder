# ppigFinder

**Protein–Protein Interaction Genomic Finder**

An open-source scientific application for investigating
candidate protein–protein interactions from bacterial genomes.

ppigFinder combines genomic analysis, ORF prediction,
sequence annotation, genomic neighborhoods, structural
prediction preparation, and downstream result interpretation.

## Execution environments

ppigFinder is not restricted to a specific HPC cluster,
scheduler, or structural prediction backend.

The application supports preparation of structural
prediction inputs for compatible services, including
manual AlphaFold Server workflows.

Local execution and remote HPC workflows depend on
the available backend and configured environment.

DaVinci is an optional institutional profile.
